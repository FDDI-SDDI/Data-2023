# Data-2023
## Dataset Description
This repository contains the dataset used in the study, derived from the Global State Development Drivers Index Report, published by the Fudan Development Institute, Fudan University. The dataset provides state-level indicators used to evaluate regional development performance and serves as the primary data source for the empirical analysis presented in the study.

## Source
Fudan Development Institute, Fudan University. Global State Development Drivers Index Report.

## Purpose of the Dataset
The normalized dataset is provided to facilitate transparency, reproducibility, and verification of the empirical results reported in the study. Researchers may use the dataset to replicate the analysis and conduct related research, subject to the terms and conditions of the original data source.

## Data Structure
The dataset includes the variables and observations used in the empirical analysis. Detailed definitions and sources of individual variables are provided in the manuscript.
